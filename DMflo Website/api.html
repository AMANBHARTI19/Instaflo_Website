DMflo API Reference

Two endpoints. Machine-readable OpenAPI spec available at /api/openapi.yaml.

Endpoints

MethodPathScopeDescription
GET/api/geogeo:readReturns visitor country and region for pricing routing
POST/api/waitlistwaitlist:writeSubmit a new waitlist entry to Notion

Authentication

DMflo uses OAuth 2.0. Request only the scopes your agent needs. See authentication docs for details.

Scopes

  • geo:read — Read geographic routing data
  • waitlist:write — Submit a waitlist entry
  • waitlist:read — Read existing waitlist entries

Full scope declarations: /.well-known/protected-resource.json
